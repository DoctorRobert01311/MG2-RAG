# 我的科研笔记

这些 Markdown（.md）文件就是本地笔记，VS Code 可以直接编辑，不用安装新软件。

## 目录

- [Git 与 VS Code](01-git-vscode.md)：常用操作，遇到新知识继续补充。
- [科研日志](research-log.md)：按日期追加实验和学习记录。
- [新笔记模板](template.md)：读论文、看代码、做实验时复制使用。

## 新建与保存

1. 在 VS Code 左侧右键 study-notes → 新建文件。
2. 命名如 02-mg2-code-flow.md 或 2026-10-31-retrieval.md。
3. 写内容，按 ⌘S，即已保存到本机。按 ⌘⇧V 可预览 Markdown。
4. 每次学习结束后，用 Git 保存一个版本；联网并配置好个人仓库后可再推送作远程副本。

先用这一份目录，不用分类太细。每次至少记录：做了什么、结果是什么、下一步是什么。结果文件和图表用链接引用，不反复复制。

本目录随 Git 分支管理；切换分支时看到的笔记可能不同。日常先在 study/day01-git 这条学习分支持续积累。
