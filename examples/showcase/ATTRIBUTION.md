# Showcase data attribution

The showcase uses the InfoSeek/Wikidata sample Q132576 (Impala), preserving its
identifier so provenance remains explicit.

The query image originates from the InfoSeek validation set. Knowledge-base
images originate from the corresponding Wikipedia-linked InfoSeek corpus.
Before redistributing these images publicly, verify the license and attribution
requirements of each original Wikimedia file and the InfoSeek dataset terms.
